      Integration boundary

      Fulfillment must wait for trusted server-side payment status.

      Confirm fulfillment through a trusted signed callback or Partner API read on your server.

      Browser success is user experience feedback, not fulfillment authority.

      Integration reference

      Configure only the public API base URL, public site key, server-owned price key, and locale. Keep fulfillment and every administrative credential on a trusted server.
